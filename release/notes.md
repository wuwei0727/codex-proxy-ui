# v0.9.0

## 新增功能

- 新增 `ZSidebar`，支持折叠、分组导航，以及自定义品牌区和底部操作区
- 提供星津夜航、水墨江汀、粉墙回廊、朱阙金瓦四套主题预设，组合明暗配色、推荐材质、控件尺寸与组件圆角
- 卡片和侧边栏支持柔光材质，可独立于配色切换

## 组件调整

- 颜色选择器的确认按钮使用主按钮样式，面板可随可用宽度收窄
- 日期和日期范围默认不显示占位文字，英文下拉框的默认提示改为 `Select`；显式传入的占位文字保持不变

## 安装

```bash
pnpm add https://github.com/zyycn/codex-proxy-ui/releases/download/v0.9.0/codex-proxy-ui-0.9.0.tgz
```

需要 Node.js 24+、Vue 3.5+，包名为 `@codex-proxy/ui`
